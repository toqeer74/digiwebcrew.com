Vanguard was spending well on paid campaigns but sending everything to a single generic homepage. Traffic arrived, looked around, and left.

## The challenge

One page had to serve every campaign, every property type, and every buyer intent at once — so it served none of them well. A visitor arriving from an ad about waterfront apartments landed on the same page as someone searching for commercial units.

The bigger problem sat behind the form. Enquiries dropped into a shared inbox and waited for whoever checked it next. In a market where the first responder usually wins the instruction, several hours of delay was quietly costing them deals.

## Our approach

We treated the campaign and the landing page as a single unit. If an ad promises something specific, the page has to continue that exact conversation — same property type, same language, same offer — and ask for one clear action.

We also mapped what happened after the form submit, because a faster page is worthless if the follow-up still takes four hours.

## What we built

We built a set of focused landing pages, each matched to a campaign and property type, with the viewing request as the single clear action on the page.

Behind the form, an automation layer routes each enquiry to the right agent based on property type and location, sends the prospect an immediate confirmation with next steps, and escalates to a second agent if nobody responds inside the window.

## The outcome

Viewing requests tripled, and average response time fell from several hours to under five minutes. Because each page matches the campaign feeding it, cost per qualified lead dropped by nearly half — the same ad spend now produces meaningfully more instructions.
